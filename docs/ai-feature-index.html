The thirteen are not a rounding error

They are written, type-checked and covered by the registry — and nothing calls them, so no amount of clicking will find them. They were reported as reachable until a call-site audit caught it, because the original check only proved the code existed. scripts/ai-reachability.mjs now recomputes this from the source on demand, so the list stays honest.

The model is also not connected yet. Retrieval, citations, refusals, confirmation and undo are all real; the language is generated deterministically until an API key is set. Nothing on this page changes when it is.
